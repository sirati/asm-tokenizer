# Setup Guide

This document describes how to set up the development environment for the asm-tokenizer project using Nix flakes and direnv.

## Prerequisites

You need to install the following system-wide:

1. **Nix with flakes enabled**
2. **direnv**
3. **nix-direnv** (optional but highly recommended for performance)

## System-Wide Installation

### 1. Install Nix

If you don't have Nix installed:

```bash
# Official installer with flakes enabled
sh <(curl -L https://nixos.org/nix/install) --daemon
```

### 2. Enable Nix Flakes

Add this to `~/.config/nix/nix.conf` (create the file if it doesn't exist):

```
experimental-features = nix-command flakes
```

### 3. Install direnv

Choose one of the following methods:

**Using Nix (recommended):**
```bash
nix profile install nixpkgs#direnv
```

**Using your system package manager:**
```bash
# Ubuntu/Debian
sudo apt install direnv

# Fedora
sudo dnf install direnv

# macOS (Homebrew)
brew install direnv
```

### 4. Configure direnv for your shell

Add the appropriate hook to your shell's RC file:

**For Bash** (`~/.bashrc`):
```bash
eval "$(direnv hook bash)"
```

**For Zsh** (`~/.zshrc`):
```bash
eval "$(direnv hook zsh)"
```

**For Fish** (`~/.config/fish/config.fish`):
```fish
direnv hook fish | source
```

After adding the hook, restart your shell or source the RC file:
```bash
source ~/.bashrc  # or ~/.zshrc
```

### 5. Install nix-direnv (Recommended)

nix-direnv dramatically improves performance by caching the development environment.

Create `~/.config/direnv/direnvrc` and add:

```bash
source $HOME/.nix-direnv/direnvrc
```

Then install nix-direnv:

```bash
nix profile install nixpkgs#nix-direnv
```

Or manually:
```bash
mkdir -p ~/.nix-direnv
git clone https://github.com/nix-community/nix-direnv ~/.nix-direnv
```
